# 🌍 Restaurant Geographic Analysis

## 📌 Project Overview

This project performs **Geographic Analysis of Restaurants** using their latitude and longitude coordinates.

The project uses Python to analyze restaurant location data and visualize the geographical distribution of restaurants on an interactive map.

The interactive map is created using **Folium**, with each restaurant represented as a marker based on its geographical coordinates.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze the geographical distribution of restaurants.
- Identify restaurant locations using latitude and longitude.
- Create an interactive restaurant location map.
- Understand how restaurants are distributed across different geographical regions.
- Practice data analysis and geographical visualization using Python.

---

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data loading and data handling
- **Folium** – Interactive geographical visualization
- **CSV Dataset** – Restaurant location and other restaurant information

---

## 📂 Dataset

The project uses a restaurant dataset containing **9,551 restaurant records** and **21 attributes**.

Important columns used in this project include:

- `Restaurant Name`
- `City`
- `Address`
- `Locality`
- `Longitude`
- `Latitude`
- `Cuisines`
- `Average Cost for two`
- `Price range`
- `Aggregate rating`
- `Votes`

The `Latitude` and `Longitude` columns are used to determine the geographical position of each restaurant.
